# 🎂 مشروع عيد ميلاد إسراء — Visual Studio Code

المشروع معمول من الصفر بـ HTML وCSS وJavaScript فقط. مفيش مكتبات خارجية، ومناسب للرفع على GitHub Pages.

## الملفات

- `index.html`: النصوص وعناصر الصفحة والأزرار.
- `style.css`: الألوان والخلفية والتورتة والأنيميشن والتجاوب مع الموبايل.
- `script.js`: ترتيب ظهور طبقات التورتة، الشمعة، المؤثرات الصوتية، والرسالة.
- `assets/`: مجلد متاح لإضافة صور أو أصوات خاصة لاحقًا، لكنه مش مطلوب لتشغيل النسخة الحالية.

## فتح المشروع في VS Code

1. نزّل ملف ZIP وفك ضغطه في مكان تعرف توصله.
2. افتح Visual Studio Code.
3. من **File → Open Folder** اختار مجلد `esraa-birthday-vscode` بعد فك الضغط.
4. من الشريط الجانبي افتح `index.html`.
5. أسهل طريقة لمعاينة الموقع: افتح تبويب **Extensions** وابحث عن **Live Server** وثبّته، وبعدها اضغط كليك يمين على `index.html` واختر **Open with Live Server**.
6. كل ما تعدّل وتعمل حفظ، المتصفح هيحدّث الموقع تلقائيًا في العادة.

تقدر كمان تفتح `index.html` مباشرة بالمتصفح، لكن Live Server أسهل أثناء التعديل.

## أعدّل إيه وفين؟

### تغيير الألوان
افتح `style.css` وابحث عن `:root` في أول الملف. غيّر قيم المتغيرات زي `--pink-soft` و`--pink-strong`.

### تغيير الكلام
افتح `index.html` وابحث عن الجملة اللي عايز تغيّرها. نص رسالة الحب موجود داخل العنصر `letter-card` قرب نهاية الملف.

### تعديل شكل التورتة
في `style.css` ابحث عن `.tier-bottom` و`.tier-middle` و`.tier-top` لتعديل عرض وارتفاع وألوان الطبقات. أكواد الحركة موجودة عند `@keyframes cake-layer-drop`.

### تعديل توقيت الأنيميشن
افتح `script.js` وابحث عن الدالة `startSurprise`. أوامر `wait(...)` هي الفواصل الزمنية بين مراحل المفاجأة.

### الصوت
الصوت مؤثرات قصيرة مولدة داخل المتصفح، من غير موسيقى أو ملفات صوت. الصوت يبدأ فقط بعد ضغطة على زر البداية، لأن المتصفحات عادةً تمنع الصوت التلقائي.

## الرفع على GitHub Pages لاحقًا

1. أنشئ Repository جديدًا على GitHub.
2. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع، وممكن ترفع `README_AR.md` أيضًا.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختار **Deploy from a branch**.
5. اختار الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر، وبعدها يظهر رابط الموقع في إعدادات Pages.

> مهم: ارفع الملفات الثلاثة في نفس المجلد عشان روابط `style.css` و`script.js` تفضل شغالة.
